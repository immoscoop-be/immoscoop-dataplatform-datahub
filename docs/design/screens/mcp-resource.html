  2. 1Read first

    What it is

    The number of credit leads we send to KBC each week, per lead source. Use it to follow the trend and to compare sources.

    • It counts leads, not people: someone who applies twice counts twice.

    From dbtOne row per week and lead source with the number of credit leads sent to KBC. Test and duplicate requests are excluded.

  3. 2Read first

    One row is

    One week × one lead source week_startlead_source · an aggregate, counted per week.

  5. 4Before you query

    How to query it cheaply

    Filter on week_start first, a partition per week: without it a query reads all 6.2 GB, with it about 20 MB a week. Then on lead_source, the first cluster column.

    Key fields week_startlead_sourcelead_count · Parameters lead_sourceweek_start

  7. 6When interpreting results

    Watch out

    The current week is incomplete. Don’t sum across sources for unique people. Reliable since 1 Jan 2025.

  8. 7When interpreting results
