What it does, step by step
  1. Takes the weekly lead volume between From and To.
  2. Adds the name of each lead source.
  3. Adds up the leads per source and puts the largest first.
Show the SQL
select s.source_name,
       sum(v.lead_count) as leads
from weekly_lead_volume as v
join lead_sources as s using (lead_source)
where v.week_start between @dateFrom and @dateTo
group by s.source_name
order by leads desc
