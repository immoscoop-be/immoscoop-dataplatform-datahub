Distribution of categories

What it does

It counts, per text field, how much each value brings: the values, the most first, with their share, and the rest together.

Why it matters

A category with one value that brings nearly everything, or a hundred that each bring almost nothing, changes every comparison by it. And two ways of writing one value split it in two in every report.

Parameters

lead_sourcelead_channelThe text fields among its Key Fields. Add a field
Weighed by
A number that adds up, its role first, or rows. For an aggregate a row is a week and a lead source, so rows would weigh every source alike. A unique count, such as unique_applicants, never adds up, so it is not offered.
