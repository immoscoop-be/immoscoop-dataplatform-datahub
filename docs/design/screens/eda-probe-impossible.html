Impossible values

What it does

It checks every value against what can be true for its field: a week that has not begun yet, a number of leads below zero, a channel that does not exist. Each field gets its own rule.

Why it matters

An impossible value is wrong for certain, unlike an outlier, which may be real. It skews every sum and average it is in, and often points to a fault in how the data is made.
