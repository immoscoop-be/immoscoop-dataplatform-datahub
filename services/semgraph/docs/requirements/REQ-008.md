## Requirement

> Een mediaan is een bol (in een brede balk of met een band voor P25–P75). Een lopende periode is een holle bol.

## Zo geïmplementeerd

- Een mediaan is een bol van 7 px. Dat is het token `mark.circle`, voorlopig, in verhouding tot Figma (9 px).
- Een definitieve waarde is gevuld, een lopende periode is hol, zoals bij [REQ-006](REQ-006.md).
- Met weinig punten staat de bol in een brede, afgeronde balk van P25 tot P75.
- Met veel punten wordt de spreiding een band langs de lijn. Een bol staat dan nog op het laatste punt, op een
  lopende periode en op een los punt.

## Code en tests

- Dezelfde code als [REQ-006](REQ-006.md): `src/charts/signatures.ts`, `Statistic.shape`, de laag `points`.
- `test/requirements.test.ts`, de tests "REQ-006 and REQ-008".
- `test/render.test.ts`: de brede balk bij een mediaan, de smalle bij een gemiddelde.

## Samenhang

- [REQ-013](REQ-013.md) bracht de mediaan. Deze requirement legt haar vorm vast.
- Met een band staat er enkel een bol op het laatste punt: bevestigd op 2026-10-03 als [REQ-017](REQ-017.md).
