## Requirement

> Enkel een achterstand tegenover de vorige periode wordt gearceerd (verlies). Een winst krijgt geen vulling.

## Zo geïmplementeerd

- Tussen de twee lijnen wordt gearceerd waar de focusreeks onder de vergelijking ligt. Waar de lijnen kruisen,
  wordt het vlak afgesneden.
- Een winst krijgt niets. Over een gat in een van beide lijnen wordt nooit gearceerd.
- De arcering is een SVG-patroon: donkere schuine lijnen op wit, zoals in het Figma-voorbeeld. Het patroon heeft
  een id die per grafiek uniek is ([REQ-036](REQ-036.md)).

## Code en tests

- `src/charts/comparison.ts`: `shortfall()`, `hatchPattern()`, `patternId()`.
- `test/requirements.test.ts`, de test "REQ-004": geen arcering bij winst, en de randen van de arcering zijn exact
  de twee lijnen.

## Samenhang

- "Hatching keeps one meaning everywhere: loss against a reference" (Figma). Dat vervangt de oudere lezing van de
  analyse dat arcering enkel voor de funnel dient.
